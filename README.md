# SpecialSpinist — Playable demo

[Play SpecialSpinist](https://syamashi.github.io/special-spinist-play/)

A special-spin puzzle practice game with a two-minute All Spin score challenge.
Desktop keyboard controls: arrows to move/rotate, Z to rotate counterclockwise,
A for 180-degree rotation, C for Hold, Space for hard drop, F8 for debug values.
Controls and handling can be changed in Settings.

This repository contains compiled distribution files only. The source repository
is private. No source maps, player logs, account credentials, or development
settings are published here. Browser-delivered JavaScript and puzzle definitions
can necessarily be inspected by players.

Scores and progress are stored in the player's browser. Online accounts,
leaderboards, and payments are not part of this free demo.
